# Simulation of Radiation-Hardened SRAM for Space Applications

> **Status: Ongoing research project**

Study and simulation of SRAM cells for radiation environments, focusing on **Single Event Upsets (SEUs)** and **Radiation-Hardened-by-Design (RHBD)** techniques for space-grade memory.

## Motivation

In space, energetic particles striking a memory cell can flip its stored bit (a Single Event Upset). Standard SRAM cells are vulnerable to this, so space-grade memory relies on design-level hardening to keep data reliable.

## What I'm doing

- Designed and simulated **6T SRAM** cells in Cadence Virtuoso as the baseline
- Analysed read, write and hold operations along with **Static Noise Margin (SNM)**
- Studying SEUs and their impact on SRAM reliability in radiation environments
- Investigating **RHBD** techniques to improve SRAM robustness
- Conducting a literature review on SEU mitigation, RHBD SRAM and space-grade memory design

- Cadence Virtuoso
